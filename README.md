# Flipkart Customer Retention Analysis

## Project Overview
Analysis of 30,000 Flipkart customer service call records to identify 
key factors affecting customer satisfaction and retention.

## Tools Used
- Microsoft Excel (Pivot Tables, Charts, Dashboard)

## Key Findings
- Sentiment is the strongest driver of CSAT scores
- Kolkata call center has the lowest CSAT (5.46)
- Chatbot has the lowest satisfaction score among all channels
- Thursday has the highest call volume and lowest CSAT

## Files
- `Milestone 1_fathima hanaan.xlsx` — Excel workbook with pivot tables and dashboard
- `Milestone 1 report_Fathima hanaan.pdf` — Detailed analysis report

## Dataset
30,000 customer service call records including sentiment, 
CSAT scores, call duration, channel, and call center data.
